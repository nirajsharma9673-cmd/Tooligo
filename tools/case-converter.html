Case Converter

Convert text between different letter cases instantly

Your Text

How It Works

This tool applies JavaScript string transformations to change the case of your text. Each mode works differently:

  • UPPERCASE — Converts every letter to uppercase.
  • lowercase — Converts every letter to lowercase.
  • Title Case — Capitalizes the first letter of every word; the rest are lowercase.
  • Sentence case — Capitalizes the first letter of each sentence; everything else is lowercase.
  • aLtErNaTiNg CaSe — Alternates uppercase/lowercase starting with uppercase at position 0.

How to Use

  1. Type or paste your text
  2. Click a case button to transform the text in place
  3. Use Copy to Clipboard to save the result
  4. Use Clear to start over

Case Types

UPPERCASE: All letters become capital

lowercase: All letters become small

Title Case: First letter of each word capitalized

Sentence case: First letter of each sentence capitalized

Frequently Asked Questions

Does this modify my original text permanently?

No. The transformation only changes what is shown in the textarea on your screen. Nothing is saved, stored, or transmitted. You can always undo by clearing and re-pasting your original text.

What's the difference between Title Case and Sentence case?

Title Case capitalizes the first letter of every word (e.g., "The Quick Brown Fox"). Sentence case capitalizes only the first letter of each sentence (e.g., "The quick brown fox. It jumps high.").

Does the clipboard copy work on mobile?

Yes. The tool uses the standard browser Clipboard API (navigator.clipboard.writeText), which works on all modern browsers including mobile Chrome, Safari, and Firefox.

Is there a character limit?

No. There is no imposed character limit. The textarea can handle large blocks of text, and all transformations run in your browser without sending data anywhere.
