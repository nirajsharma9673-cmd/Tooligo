How It Works

This currency converter uses a standard reference-based conversion system. Every currency is first converted to Indian Rupees (INR) using a stored exchange rate, then converted to the target currency. This ensures accurate conversions between any pair of supported currencies.

Conversion Formula: Amount in Target = (Amount in Source × Source Rate) ÷ Target Rate, where rates are relative to INR.

Worked Example

Convert USD 100 to EUR: Using the reference rates (USD 1 = Rs 83.12, EUR 1 = Rs 90.45), the calculation is: (100 × 83.12) ÷ 90.45 = EUR 91.90 (approximately). You can verify by switching the “From” and “To” currencies to check the reverse conversion.
