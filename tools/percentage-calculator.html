About This Calculator

This percentage calculator helps you calculate percentages in three different ways: find percentage of a number, calculate percentage change, and find what percent one number is of another.

How to Use

  1. Select the calculation type
  2. Enter the required values
  3. Click Calculate
  4. Get instant results

Formulas Used

  • X% of Y: (X × Y) / 100
  • % Change: ((New - Old) / Old) × 100
  • X is what % of Y: (X / Y) × 100

Frequently Asked Questions

How do I calculate a percentage of a number?

Use the formula: (Percentage × Number) / 100. For example, 20% of 100 = (20 × 100) / 100 = 20.

What's the formula for percentage increase?

Formula: ((New Value - Original Value) / Original Value) × 100. For example, if value increased from 100 to 120, increase = ((120-100)/100) × 100 = 20%.

Can I use this for discounts?

Yes! If an item is 30% off, select "What is X% of Y?" and calculate 30% of the original price to find discount amount.
