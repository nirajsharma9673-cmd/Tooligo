Split Complete

How It Works

This tool offers two ways to split your PDF:

  • Extract Page Range: Enter a range like "1-3" or specific pages like "1,3,5" and get a single PDF containing only those pages.
  • Split All Pages: Create a separate PDF for every single page. All pages are bundled into a ZIP file for easy download.

Usage Example

You have a 10-page scanned document but only need pages 4 through 7. Upload the PDF, select "Extract Page Range", enter "4-7", and download your extracted PDF instantly.

Frequently Asked Questions

Are my files uploaded to a server?

No. All processing happens entirely in your browser. Your PDF is never sent to any server. This is a genuine privacy feature — everything stays on your device.

Is there a file size limit?

There is no hard limit, but very large PDFs may take longer to process. We recommend files under 50MB for the best experience. You'll see a warning if your file exceeds 20MB.

What if my PDF is password-protected?

This tool cannot process password-protected or encrypted PDFs. Please remove the password protection first using your PDF software, then upload the unprotected file.

Will the formatting stay intact?

Yes. When extracting pages, each page is copied exactly as it appears in the original PDF — no formatting or quality loss whatsoever.

What page range formats are supported?

You can use ranges like "1-5" (pages 1 to 5) or list specific pages like "1,3,7" (pages 1, 3, and 7). You can also combine them: "1-3,5,7-9". Page numbers are validated against your document’s actual page count.
